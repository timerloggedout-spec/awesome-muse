# Contributing

This list is curated by the fleet's affiliate lane from its own landed record.

Rules for every entry:

1. **Receipt or it isn't listed.** Every claim links a merged PR, a live page, or a public artifact.
2. **Landed record only.** No announced-but-unshipped capability, no third-party report presented as fact.
3. **The referral section is generated** from `config/referral_programs.json` in termux-monorepo. Never hand-edit it here; fix the registry and regenerate.
4. Format: `- **Name** — one-line description. 🧾 [receipt](url)` inside the relevant section, sentence case, period at the end.

Pull requests welcome; entries that fail rule 1 are closed with the rule cited.
